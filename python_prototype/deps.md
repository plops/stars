# Python Dependencies

| Package | Purpose | GitHub Organization |
|---|---|---|
| `twirl` | Plate solving and WCS computation | `lgrcia` |
| `astropy` | Coordinate transformations, WCS, FITS handling | `astropy` |
| `astroquery` | Querying Gaia catalog | `astropy` |
| `photutils` | Star detection (DAOStarFinder) | `astropy` |
| `numpy` | Numerical operations, array handling | `numpy` |
| `matplotlib` | Generating diagnostic plots | `matplotlib` |
| `Pillow` | Image loading (JPEGs) | `python-pillow` |
| `exifread` | Extracting EXIF tags from images | `ianare` |
| `scipy` | Polynomial fitting for distortion | `scipy` |
| `sep` | Source extraction alternative (failed to install due to missing Python.h) | `kbarbary` |
